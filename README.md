# TimeCapsule · 时光胶囊日记

> 把每天的记忆封存起来，多年后打开，仍然鲜活。

TimeCapsule 是一个简约的网页日记应用：记录文字、插入照片、按日期整理、随时搜索回看。

**无需注册、无需登录、无需付费。** 打开网址即可开始写日记。

---

## 快速开始

1. 在浏览器中打开 TimeCapsule 的网址：chandlercui.github.io/TimeCapsule。
2. 点击右上角蓝色的 **写日记** 按钮。
3. 写下标题和内容，选一个当天的天气，有照片就点 **添加图片** 插入。
4. 点 **保存**，回到列表页就能看到你的日记了。

就这么简单，三步完成第一篇日记。

---

## 为什么不需要注册和登录？

TimeCapsule 是一款"本地优先"的日记应用：

- 你的日记**只保存在你自己的浏览器里**，不会上传到任何服务器。
- 这意味着没有账号密码要记，也没有人能看到你的日记——包括我们。
- 刷新页面、关闭浏览器、明天再打开，日记都还在。

### 需要注意的一点

正因为数据存在本机浏览器里：

- **换电脑或换浏览器**：日记不会跟着走，只在你写日记的那台设备上。
- **清理浏览器缓存/站点数据**：会连同日记一起清除。
- 想长期保存重要内容，可以偶尔手动备份（把正文复制到别处，或导出图片）。

| 记录概览 | 列表页顶部显示总篇数、连续记录天数、本月篇数 |

| 天气记录 | 晴、多云、阴、小雨、雷阵雨、雪、大风、雾，共 8 种可选 |
| 深色模式 | 右上角按钮一键切换深/浅色主题，首次自动跟随系统 |
| 备份与恢复 | 列表页可一键导出全部日记为 JSON 备份，随时恢复回来 |
| 导出 PDF | 编辑页底部点"导出 PDF"，自动按 A4 排版生成文件（标题、日期、天气、心情、正文、照片一页不少），多页日记自动分页且不切断照片 |

## 常见问题

**Q：换电脑后日记不见了？**
因为日记保存在原电脑的浏览器里。目前版本不支持跨设备同步，但可以在列表页点"备份全部"导出 JSON，换设备后点"恢复备份"导入。

**Q：清理浏览器数据会丢日记吗？**
会。清除浏览器缓存/站点数据时，TimeCapsule 的数据也会被清除。重要日记建议定期备份。

**Q：我的日记安全吗？会不会被别人看到？**
安全。日记只存在你自己的浏览器里，不会上传服务器，其他人无法访问。

**Q：怎么删掉一篇日记？**
打开该日记，点编辑器底部左侧的红色"删除日记"即可（会先弹确认，防止误删）。

**Q：草稿会自动保存吗？**
会。写日记时输入内容会自动保存在本机浏览器，即使误关页面，再次打开这篇日记也会自动恢复草稿；保存成功后会清除该篇草稿。

**Q：导出的 PDF 保存在哪里？**
点"导出 PDF"后，文件会像普通下载一样保存到浏览器的下载目录（手机上会弹出到"文件"App）。文件名格式为"时光胶囊_日期_标题.pdf"。导出完全在本地完成，断网也能用；若浏览器不支持自动生成，会自动切换到打印面板，选择"存储为 PDF"即可。

**Q：分享图片是什么？**
点"分享图片"会把当前日记（标题、日期、天气、心情、正文、标签）渲染成一张竖版卡片 PNG 并保存到本地，随手发到社交平台，比截图更精致。

**Q：最多能写多少篇？**
本地存储空间足以支撑多年的日记（取决于浏览器和图片数量）。
