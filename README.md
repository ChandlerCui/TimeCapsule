# TimeCapsule · 时光胶囊日记

> 把每天的记忆封存起来，多年后打开，仍然鲜活。

TimeCapsule 是一个简约的网页日记应用：记录文字、插入照片、按日期整理、随时搜索回看。

**无需注册、无需登录、无需付费。** 打开网址即可开始写日记。

---

## 快速开始

1. 在浏览器中打开 TimeCapsule 的网址（你的朋友会把这个链接发给你）。
2. 点击右上角蓝色的 **写日记** 按钮。
3. 写下标题和内容，选一个当天的天气，有照片就点 **添加图片** 插入。
4. 点 **保存**，回到列表页就能看到你的日记了。

就这么简单，三步完成第一篇日记。

---

## 为什么不需要注册和登录？

TimeCapsule 是一款"本地优先"的日记应用：

- 你的日记**只保存在你自己的浏览器里**，不会上传到任何服务器。
- 这意味着没有账号密码要记，也没有人能看到你的日记——包括我们。
- 刷新页面、关闭浏览器、明天再打开，日记都还在。

### 需要注意的一点

正因为数据存在本机浏览器里：

- **换电脑或换浏览器**：日记不会跟着走，只在你写日记的那台设备上。
- **清理浏览器缓存/站点数据**：会连同日记一起清除。
- 想长期保存重要内容，可以偶尔手动备份（把正文复制到别处，或导出图片）。

## 功能介绍

| 功能 | 怎么用 |
| --- | --- |
| 写日记 | 点右上角"写日记"，输入标题、正文，选择天气 |
| 插入图片 | 编辑器里点"添加图片"，从电脑选择照片（支持 JPG/PNG，最多 9 张） |
| 编辑图片 | 图片右上角可**旋转**、**删除**，下方还能写图片说明 |
| 搜索日记 | 列表页顶部搜索框，输入关键词即可全文搜索（按标题和正文匹配） |
| 按日期排序 | 列表页右侧切换"最新优先 / 最早优先" |
| 天气记录 | 晴、多云、阴、小雨、雷阵雨、雪、大风、雾，共 8 种可选 |

## 常见问题

**Q：换电脑后日记不见了？**
因为日记保存在原电脑的浏览器里。目前版本不支持跨设备同步，这是本地存储的设计使然。

**Q：清理浏览器数据会丢日记吗？**
会。清除浏览器缓存/站点数据时，TimeCapsule 的数据也会被清除。

**Q：我的日记安全吗？会不会被别人看到？**
安全。日记只存在你自己的浏览器里，不会上传服务器，其他人无法访问。

**Q：怎么删掉一篇日记？**
打开该日记，点编辑器底部左侧的红色"删除日记"即可。

**Q：最多能写多少篇？**
本地存储空间足以支撑多年的日记（取决于浏览器和图片数量）。
